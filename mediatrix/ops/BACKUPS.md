كل تعديل يُحفظ بثلاث طرق، ويمكن الرجوع لأي نقطة:

| النوع | أين | كيف أرجع |
|---|---|---|
| **الكود** | كل commit في فرع `claude/relaxed-maxwell-7t6pxu` على GitHub | `git checkout <commit> -- mediatrix` ثم النشر |
| **الموقع المنشور** | كل نشر = نسخة في Cloudflare (Workers → mediatrix → Deployments) | من لوحة Cloudflare: **Rollback** لأي نسخة، أو `npx wrangler rollback <version-id>` |
| **المحتوى (نصوص، روابط، صور)** | تلقائياً قبل كل حفظ من لوحة التحكم (آخر ٣٠ نسخة) | لوحة التحكم → **النسخ الاحتياطية** → استرجاع |
| **لقطات محتوى يدوية** | `ops/backups/content-*.json` | ترسلها لي وأسترجعها |
