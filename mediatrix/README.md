# Mediatrix — الموقع الرسمي + لوحة التحكم

موقع تعريفي فاخر لعلامة **Mediatrix** يعمل كبوابة موحّدة لمتاجرها في كل دولة، مع لوحة تحكم كاملة.
التصميم مستوحى من الفيلم التعريفي: خلفية أزرق مثلجي، ذهبي فاخر، شريط حريري، ومعالم متحركة لكل دولة.

## المزايا
- **عربي / إنجليزي** (`/ar` و `/en`) مع RTL كامل، واختيار اللغة تلقائياً حسب المتصفح.
- **شاشة افتتاحية**: خط النبض يرسم نفسه ثم يظهر الاسم (مرة واحدة لكل زيارة).
- **بانر المنتجات المتحرك** (SVG): حرير فضي متموج، شريط ذهبي، لمعة على الزجاج، قطرات وفقاعات ونجوم، وحركة Parallax مع الماوس.
- **بطاقات الدول**: رسوم متحركة لكل معلم (تمثال الحرية، بوابة براندنبورغ، بيغ بن، برج خليفة، برج المملكة، أبراج الكويت) مع غيوم وألعاب نارية وأشعة ضوء، وضوء ذهبي يدور على البطاقات بالتتابع. يمكن استبدال أي رسم بصورة أو فيديو من اللوحة.
- **روابط المتاجر** عبر `/go/<id>`: تُحسب النقرات وتضاف روابط تتبع UTM تلقائياً. بدون رابط يظهر زر «قريباً».
- **إبراز دولة الزائر** تلقائياً (عند الاستضافة على Vercel أو خلف Cloudflare).
- الأقسام: من نحن وقصتنا، الرؤية والرسالة والأهداف، الخدمات، الفروع، الشركاء (شريط متحرك)، معرض الصور، تواصل معنا (نموذج + زر واتساب عائم)، سياسة الخصوصية.
- SEO: عناوين وأوصاف لكل لغة، Open Graph، sitemap و robots، و Google Analytics اختياري.

## لوحة التحكم `/admin`
نظرة عامة (زيارات يومية، نقرات كل متجر، رسائل جديدة) • الهوية والألوان والشعار • الدول والمتاجر (إضافة/حذف/ترتيب/إخفاء + معاينة مباشرة) • من نحن والرؤية • الخدمات • الفروع • الشركاء • معرض الصور • التواصل والسوشال • ترتيب الأقسام وإظهارها • SEO والخصوصية • صندوق الرسائل • تغيير كلمة المرور.

الحماية: كلمة مرور مشفّرة (bcrypt)، جلسة موقّعة (JWT في كوكي httpOnly)، حدّ لمحاولات الدخول، وفلترة الروابط والملفات المرفوعة.

## التشغيل محلياً
```bash
cp .env.example .env.local   # عدّل ADMIN_PASSWORD و AUTH_SECRET
npm install
npm run dev                  # http://localhost:3000  — اللوحة: /admin
```

## النشر
المحتوى والصور والإحصائيات تُحفظ في مجلد `DATA_DIR` (ملفات JSON + uploads)، لذلك يلزم خادم Node بقرص دائم
(VPS، أو Railway / Render / Fly.io مع Volume، أو Docker):
```bash
docker build -t mediatrix .
docker run -d -p 3000:3000 -v mediatrix-data:/data \
  -e ADMIN_PASSWORD='...' -e AUTH_SECRET="$(openssl rand -hex 32)" -e SITE_URL='https://your-domain' mediatrix
```
> ملاحظة: Vercel لا يحفظ الملفات بين الطلبات؛ للنشر عليه يجب استبدال طبقة التخزين (`src/lib/store.ts`) بقاعدة بيانات مثل Supabase.

## البنية
```
src/app/(site)/[lang]     الموقع العام
src/app/(admin)/admin     لوحة التحكم
src/app/api/...           واجهات الحفظ والرفع والتتبع والتواصل
src/components/art        الشعار، البانر، رسوم المعالم المتحركة
src/components/site       أقسام الموقع
src/components/admin      مكوّنات اللوحة
src/lib                   النوعيات، المحتوى الافتراضي، التخزين، المصادقة
```
