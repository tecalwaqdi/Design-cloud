# Mediatrix — الموقع الرسمي + لوحة التحكم

موقع تعريفي فاخر لعلامة **Mediatrix** يعمل كبوابة موحّدة لمتاجرها في كل دولة، مع لوحة تحكم كاملة.
التصميم مستوحى من الفيلم التعريفي: خلفية أزرق مثلجي، ذهبي فاخر، شريط حريري، ومعالم متحركة لكل دولة.

## المزايا
- **عربي / إنجليزي** (`/ar` و `/en`) مع RTL كامل، واختيار اللغة تلقائياً حسب المتصفح.
- **شاشة افتتاحية**: خط النبض يرسم نفسه ثم يظهر الاسم (مرة واحدة لكل زيارة).
- **بانر المنتجات المتحرك** (SVG): حرير فضي متموج، شريط ذهبي، لمعة على الزجاج، قطرات وفقاعات ونجوم، وحركة Parallax مع الماوس.
- **بطاقات الدول**: رسوم متحركة لكل معلم (تمثال الحرية، بوابة براندنبورغ، بيغ بن، برج خليفة، برج المملكة، أبراج الكويت) مع غيوم وألعاب نارية وأشعة ضوء، وضوء ذهبي يدور على البطاقات بالتتابع. يمكن استبدال أي رسم بصورة أو فيديو من اللوحة.
- **روابط المتاجر** عبر `/go/<id>`: تُحسب النقرات وتضاف روابط تتبع UTM تلقائياً. بدون رابط يظهر زر «قريباً».
- **إبراز دولة الزائر** تلقائياً (عند الاستضافة على Vercel أو خلف Cloudflare).
- الأقسام: من نحن وقصتنا، الرؤية والرسالة والأهداف، الخدمات، الفروع، الشركاء (شريط متحرك)، معرض الصور، تواصل معنا (نموذج + زر واتساب عائم)، سياسة الخصوصية.
- SEO: عناوين وأوصاف لكل لغة، Open Graph، sitemap و robots، و Google Analytics اختياري.

## لوحة التحكم `/admin`
نظرة عامة (زيارات يومية، نقرات كل متجر، رسائل جديدة) • الهوية والألوان والشعار • الدول والمتاجر (إضافة/حذف/ترتيب/إخفاء + معاينة مباشرة) • من نحن والرؤية • الخدمات • الفروع • الشركاء • معرض الصور • التواصل والسوشال • ترتيب الأقسام وإظهارها • SEO والخصوصية • صندوق الرسائل • تغيير كلمة المرور.

الحماية: كلمة مرور مشفّرة (bcrypt)، جلسة موقّعة (JWT في كوكي httpOnly)، حدّ لمحاولات الدخول، وفلترة الروابط والملفات المرفوعة.

## التشغيل محلياً
```bash
cp .dev.vars.example .dev.vars   # عدّل ADMIN_PASSWORD و AUTH_SECRET
npm install
npm run dev                      # http://localhost:3000  — اللوحة: /admin
npm run preview                  # تشغيل نسخة Cloudflare الفعلية محلياً (http://localhost:8787)
```
محلياً تُحاكى قاعدة D1 ومخزن R2 تلقائياً داخل مجلد `.wrangler/`.

## النشر على Cloudflare
يعمل الموقع على **Cloudflare Workers** عبر محوّل OpenNext (الطريقة الرسمية الحالية لـ Next.js على Cloudflare؛
محوّل Pages القديم `next-on-pages` أصبح متوقفاً).

| المكوّن | الاستخدام |
|---|---|
| Workers | تشغيل الموقع ولوحة التحكم |
| D1 `mediatrix-db` | المحتوى، الإحصائيات، الرسائل، كلمة المرور |
| R2 `mediatrix-media` | الصور والفيديوهات المرفوعة |

قاعدة D1 ومخزن R2 **تُنشآن تلقائياً** في أول نشر، والجداول تُنشأ تلقائياً عند أول طلب.

### الطريقة ١: ربط GitHub من لوحة Cloudflare (موصى بها — نشر تلقائي مع كل تحديث)
1. Cloudflare Dashboard ← **Workers & Pages** ← **Create** ← **Import a repository** واختر هذا المستودع.
2. الإعدادات:
   - **Root directory:** `mediatrix`
   - **Build command:** `npx opennextjs-cloudflare build`
   - **Deploy command:** `npx opennextjs-cloudflare deploy`
3. بعد أول نشر: Worker ← **Settings ← Variables and Secrets** وأضف (كـ Secret):
   - `ADMIN_PASSWORD` — كلمة مرور الدخول الأولى
   - `AUTH_SECRET` — نص عشوائي طويل (`openssl rand -hex 32`)
   - `SITE_URL` — رابط الموقع النهائي (مثل `https://mediatrix.com`)
4. لربط دومينك: Worker ← **Settings ← Domains & Routes ← Add Custom Domain**.

### الطريقة ٢: من سطر الأوامر
```bash
npx wrangler login
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put AUTH_SECRET
npm run deploy
```

> الخطة المجانية تكفي للبداية (حجم الـ Worker ≈ 1.1MB مضغوط من أصل 3MB). رفع الفيديو محدود بـ 80MB للملف.

### معاينة سريعة على Vercel (للعرض فقط)
vercel.com ← **Add New ← Project** ← استورد المستودع، واجعل **Root Directory** = `mediatrix`،
وأضف `ADMIN_PASSWORD` و `AUTH_SECRET` في Environment Variables ثم **Deploy**.
على Vercel تُحفظ تعديلات اللوحة والصور في ذاكرة مؤقتة تُمسح تلقائياً، لذلك هي للعرض والتجربة فقط؛ النسخة الفعلية على Cloudflare.

### بديل: أي خادم Node
بدون Cloudflare يعمل الموقع بـ `npm run build && npm start` ويحفظ البيانات في ملفات داخل `DATA_DIR` (انظر `.env.example`).

```
src/components/art        الشعار، البانر، رسوم المعالم المتحركة
src/components/site       أقسام الموقع
src/components/admin      مكوّنات اللوحة
src/lib                   النوعيات، المحتوى الافتراضي، التخزين، المصادقة
```
