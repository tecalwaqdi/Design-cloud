## مكونات الإعلان
- **الهوك:** «تدوّر شقة من شهور… وكل ما تروح تشوف، تنصدم؟»، وهو الهوك الأول بعد تعديله للشقق.
- **التعليق الصوتي:** ElevenLabs بنموذج eleven_v4، وصوت **Faisal Alotaibi** (رجل سعودي دافي وواثق، ومخصص للإعلانات العقارية). وُزّع على 13 جملة متزامنة مع المشاهد.
- **الموسيقى:** ElevenLabs Music v2.5، مقطوعة Synthwave هادئة بلمسة شرقية (عود وقانون)، متوترة في مشهد المعاناة ثم مريحة. تأكدنا بالتفريغ النصي أنها خالية من الغناء.
- **المؤثرات:** مؤثرا Glitch والنغمة الكريستالية للفراشة من ElevenLabs، والباقي (Whooshes وImpacts وClicks وLogo Reveal) مشترك من `lufy-store-ad/assets/audio/sfx`.
- **الصور:** مولّدة بالذكاء الاصطناعي (gpt-image-2.5). تشمل: الشقة المخيّبة، وصالة وأخرى مطبخ مطلّان على الرياض، والصك والمفاتيح، والمصافحة، والعائلة تستلم المفتاح.
- **الموشن:** Remotion 4، وفيه شبكة نيون ثلاثية الأبعاد، وفراشة SVG متحركة، وانتقالات Glitch وWhip pan، وخريطة يرسم عليها مسار نيون، وختم «موثّق»، وزر CTA نابض.
- **الخطوط:** Cairo للعناوين، وTajawal للنصوص، وInter للأرقام والإيميل.
- **المزج:** FFmpeg مع Ducking للموسيقى تحت الصوت، وLoudness ‎-14 LUFS.

## ملاحظات
1. **الشعار:** صممت شعارًا نصيًا مؤقتًا («أبو كيان» مع سقف بيت نيون وفراشة) لأنه ما فيه شعار رسمي. إذا عندك شعار، أرسله وأركّبه بداله.
2. **الصور والصوت مولّدة بالذكاء الاصطناعي**، فالأشخاص والشقق ليسوا عقارات أو عملاء حقيقيين. بعض المنصات (مثل TikTok) تطلب الإفصاح عن المحتوى المولّد (AIGC).
3. سطر «شقق · فلل · أراضي» تحت الزر في الخاتمة تقدر تعدّله بسهولة في `remotion/src/AbuKayanAd.tsx`.

## إعادة البناء
```bash
scripts/prepare_public.sh
cd remotion && npm install && npm run render     # -> output/abu_kayan_video_only.mp4
cd .. && python3 scripts/mix.py                   # -> output/mix_full.wav, mix_no_vo.wav
cd output && ffmpeg -i abu_kayan_video_only.mp4 -i mix_full.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k AbuKayan_Ad_45s_1080x1920.mp4
```
