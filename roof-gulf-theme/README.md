# قالب سقف الخليج للمقاولات (Roof Gulf) — ووردبريس

قالب كتل (Block Theme) عربي بالكامل يدعم RTL، لموقع تعريفي لشركة مقاولات.

## الملف الجاهز للرفع
`roof-gulf.zip` ← من لوحة ووردبريس: **المظهر ← قوالب ← أضف جديد ← رفع قالب** ثم **تفعيل**.

## بعد التفعيل (مرة واحدة)
1. أنشئ صفحات بهذه الروابط (Slug) بالضبط، وتُطبَّق قوالبها تلقائياً:
   | العنوان | الرابط (Slug) |
   |---|---|
   | الرئيسية | `home` |
   | من نحن | `about` |
   | خدماتنا | `services` |
   | مشاريعنا | `projects` |
   | تواصل معنا | `contact` |
2. **الإعدادات ← القراءة**: اختر «صفحة ثابتة» واجعل الرئيسية = صفحة «الرئيسية».
3. **الإعدادات ← الروابط الدائمة**: اختر «اسم المقالة».
4. **الإعدادات ← عام**: اسم الموقع «سقف الخليج للمقاولات».

## تعديل بيانات التواصل
في `functions.php` داخل الدالة `roof_gulf_contact()` (الجوال، واتساب، الإيميل، العنوان) — تتحدث في الفوتر وصفحة التواصل وزر واتساب.

## تعديل المحتوى والصور
- **المظهر ← المحرر** لتعديل أي نص أو صورة مباشرة.
- الصور الحالية رسومات مؤقتة في `assets/images/` — استبدلها بصور مشاريعكم الحقيقية.

## المحتويات
- `theme.json` الألوان (كحلي/برتقالي) والخط العربي Tajawal (مدمج محلياً).
- `templates/` قوالب الصفحات، `parts/` الهيدر والفوتر، `patterns/` أقسام قابلة لإعادة الاستخدام.
- `preview/` صور معاينة للتصميم.
